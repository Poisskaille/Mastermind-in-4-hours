## Context
This project was made in 4 hours while watching Ted *(not an ad)* in C++ entirely in the console.
Their will be a web port in SDL for my own portfolio but the 4 hours results are in this repo

In this version you can select how many numbers you want to guess in how many rounds.
By default at 4 colors and 10 rounds.

You win absolutely nothing and if you lose system32 is **NOT** deleted.
